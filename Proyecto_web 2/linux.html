Administración del Sistema y Archivos

Comandos fundamentales para la navegación por el sistema de archivos, gestión de permisos y manipulación de directorios en entornos GNU/Linux.

Comando Descripción Ejemplo de Uso
ls -la Lista todos los archivos y directorios, incluidos los ocultos, con formato detallado. ls -la /var/log
chmod Modifica los permisos de lectura, escritura y ejecución de un archivo o directorio. chmod 755 script.sh
grep Busca patrones de texto dentro de archivos o salidas de comandos. grep -i "error" sys.log
htop / top Monitor de procesos en tiempo real para evaluar el uso de CPU y memoria RAM. htop

Multiplexado de Terminal (tmux)

Herramienta clave para la gestión de sesiones persistentes en servidores y terminales ligeras, permitiendo dividir la pantalla en paneles independientemente de la conexión SSH.

  • tmux new -s sesion1: Crea una nueva sesión nombrada.
  • tmux attach -t sesion1: Reorganiza y vuelve a conectarse a una sesión existente.
  • Ctrl + b seguido de %: Divide la pantalla de la terminal en dos paneles verticales.
  • Ctrl + b seguido de ": Divide la pantalla de la terminal en dos paneles horizontales.
