Administración de Red y Diagnóstico

Conjunto de comandos fundamentales para la verificación de interfaces de red, diagnóstico de conectividad y gestión de configuraciones IP en entornos Windows.

Comando Descripción Ejemplo de Uso
ipconfig Muestra la configuración de red IP actual de todas las interfaces y libera/renueva direcciones. ipconfig /all
ping Verifica la conectividad de red con otro host o dispositivo mediante el envío de paquetes ICMP. ping 8.8.8.8
tracert Rastrea la ruta completa de paquetes de red y saltos de routers hasta el destino. tracert google.com
netstat Muestra las conexiones de red activas, tablas de rutas y estadísticas de interfaces. netstat -ano

Mantenimiento y Estructura de Archivos

Utilidades esenciales de la línea de comandos para la navegación por particiones, diagnóstico de almacenamiento y gestión de directorios en CMD.

  • dir: Lista los archivos y subdirectorios contenidos en la carpeta actual.
  • cd: Cambia de directorio o muestra la ruta de la carpeta activa actual.
  • chkdsk: Revisa el estado lógico de un volumen o disco duro en busca de sectores defectuosos.
  • sfc /scannow: Escanea y reparan automáticamente los archivos protegidos del sistema operativo.
